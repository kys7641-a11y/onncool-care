# 온앤쿨케어 대상자 선정 도우미

지역사회 맞춤형 에너지 돌봄 사업 **‘온(溫) 앤 쿨(cool) 케어’**의 실무자용 대상자 선정 웹페이지입니다.

- ① 기준 중위소득 150% 판정 (직장·지역·혼합 건강보험료 3개월 평균)
- ② 1~4유형 설명과 유형별 필요서류 체크리스트
- ③ 냉·난방비 지원금액과 월 분할 금액 계산, 기관 선정 현황 시뮬레이터
- ④ 실무 가이드 (선정 체크리스트, 월 지원 절차, 조사 일정, 회계 유의사항, 문의처)
- ⑤ 판정 요약 복사 + **구글 시트 자동 기록**

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 웹페이지 본체 |
| `config.js` | 관리자 설정 (구글 시트 연결 주소, 접속 키) |
| `apps-script/Code.gs` | 구글 시트에 붙여 넣는 수신 스크립트 |

## 구글 시트 연결 (관리자 1회 설정, 약 10분)

1. [sheets.new](https://sheets.new)로 빈 구글 시트를 만들고 이름을 `온앤쿨케어 판정 기록`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 통째로 붙여 넣은 뒤 💾 저장합니다.
4. 위쪽 함수 목록에서 **`setup`** 을 고르고 **▶ 실행**을 누릅니다.
   - 권한 요청이 뜨면: 계정 선택 → *고급* → *(안전하지 않음)으로 이동* → *허용*
   - 시트에 `판정기록`, `집계` 탭이 생기면 성공입니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 이 저장소의 `config.js` → ✏️ 편집 → `endpoint: ""` 따옴표 안에 URL을 붙여 넣고 **Commit changes**.
7. 1~2분 뒤 페이지 ⑤번 탭에서 테스트 기록을 해 보고, 시트에 한 줄이 생기는지 확인합니다.

> 💡 Code.gs를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로 유지)

## 기록 규칙

- 같은 **기관명 + 대상자명**으로 다시 기록하면 새 줄을 만들지 않고 **최신 판정으로 덮어씁니다** (최초기록일시는 유지).
- 주민등록번호·휴대전화번호 형태는 페이지에서 자동으로 막습니다. 동명이인은 이름 뒤에 구분 표시(예: 김영희-2)를 붙이세요.
- `집계` 탭은 QUERY 함수로 유형×판정의견, 적합 가구 금액 합계, 기관·담당자별 건수, 서류 미구비 가구를 자동으로 보여줍니다.

## 보안·개인정보 안내

- 이 저장소는 공개입니다. 코드와 `config.js`는 누구나 볼 수 있지만, **판정 기록은 관리자 구글 시트에만** 저장됩니다.
- `token`은 무분별한 전송을 거르는 간단한 필터이며 비밀번호가 아닙니다. 기록이 이상하면 Code.gs와 config.js의 token을 함께 바꾸세요.
- 구글 시트는 공유 범위를 **필요한 직원만**으로 제한하세요.
